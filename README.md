
# DHT11 MakeCode Extension

Custom MakeCode extension for reading DHT11 temperature and humidity sensors.

## Wiring (Keyestudio Shield)

S -> Signal (P0/P1/P2 etc)
V -> 3V
G -> GND

If using a module board (with LED), no external resistor is needed.

## Blocks Provided

- DHT11 temperature (°C) on pin
- DHT11 humidity (%) on pin
- DHT11 read temperature/humidity on pin

Minimum recommended read interval: 2.5 seconds.
